# Команды и права UNKNOWN SMP

`/help` в игре показывает только те команды, которые доступны вашей роли. Все права проверяются на сервере, для команд и для кнопок GUI одинаково.

## Модерация (`usmp.mod.*`)

| Команда | Право |
|---|---|
| `/kick <игрок> [причина]` | `usmp.mod.kick` |
| `/tempban <игрок> <срок> [причина]`, `/unban <игрок>` | `usmp.mod.ban` |
| `/ban <игрок> [причина]` (навсегда) | `usmp.admin.permban` |
| `/mute <игрок> <срок\|perm> [причина]`, `/unmute` | `usmp.mod.mute` |
| `/warn <игрок> <причина>` | `usmp.mod.warn` (3 предупреждения — мут на 1 ч, 5 — бан на 1 д; настраивается) |
| `/traderestrict <игрок> <срок\|off>` | `usmp.mod.trade` |
| `/history <игрок>`, `/punish <игрок>` | `usmp.mod.history`, `usmp.mod.kick` |
| `/reports` | `usmp.mod.reports` |
| `/usmp inspect` — история блока по клику | `usmp.mod.inspect` |
| `/usmp vanish`, `/usmp tp`, `/usmp invsee`, `/usmp endersee` | `usmp.mod.vanish`, `.tp`, `.invsee` |
| `/usmp lookup <игрок> [категория] [время]` | `usmp.mod.logs` |

Сроки записываются так: `30m`, `2h`, `1d12h`, `7д`.

## Администрирование (`/usmp`, алиас `/unknownsmp`)

| Команда | Право |
|---|---|
| `/usmp` — панель владельца | `usmp.admin.panel` |
| `/usmp reload` — безопасная перезагрузка настроек | `usmp.admin.reload` |
| `/usmp status` — мониторинг | `usmp.admin.monitor` |
| `/usmp setup` — мастер настройки | владелец |
| `/usmp setspawn`, `/usmp setlobby` | `usmp.admin.world` |
| `/usmp maintenance on [сек] [причина]` / `off` | `usmp.admin.maintenance` |
| `/usmp backup now \| list \| verify <имя> \| restore <имя> [db,worlds,configs] \| cancel` | `usmp.admin.backup` (restore — только владелец) |
| `/usmp role <игрок> <роль>` | владелец или консоль |
| `/usmp money give\|take\|set <игрок> <сумма>` | `usmp.admin.economy` |
| `/usmp item give\|potion <игрок> <id>`, `/usmp item list` | `usmp.admin.items` |
| `/usmp npc create <id> <VILLAGER\|MANNEQUIN\|TRADER> [скин/профессия]`, `remove`, `move`, `list`, `name`, `dialogue`, `action`, `role`, `skin` | `usmp.admin.npc` |
| `/usmp event start <meteor\|cache\|anomaly\|merchant\|secrets>`, `/usmp event stop` | `usmp.admin.events` |
| `/usmp nether open\|close\|resetcd`, `/usmp end open\|close` | `usmp.admin.events` |
| `/usmp rollback <игрок\|*> <время> [радиус]` | `usmp.admin.rollback` |
| `/usmp auth reset\|unlock\|unregister\|revoke <ник>` | `usmp.admin.auth` |
| `/usmp bc <текст>` | `usmp.admin.broadcast` |
| `/usmp gm <0-3>` | `usmp.admin.gamemode` |

Прочие права: `usmp.admin.build` (строить в лобби и на спавне в креативе), `usmp.admin.bypass-cooldown`, `usmp.admin.bypass-combat`, `usmp.admin.instant-tp`, `usmp.admin.troll`, `usmp.mod.alerts` (уведомления о подозрительных действиях), `usmp.mod.market` (снимать чужие лоты и ордера: Shift+ПКМ).

## Роли по умолчанию (`permissions.yml`)

- `player` — `usmp.player.*`
- `helper` — жалобы, мут, предупреждения, история, оповещения
- `moderator` — всё `usmp.mod.*`
- `admin` — всё `usmp.admin.*`, кроме троллинга
- `owner` — `*`

Ранги прогрессии (Новичок → Неизвестный) с ролями не связаны и прав не дают.
