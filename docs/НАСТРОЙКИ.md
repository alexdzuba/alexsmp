# Настройки UNKNOWN SMP

Все файлы лежат в `plugins/UnknownSMP/`. Изменения применяются командой `/usmp reload`, кроме `database.yml`: он читается только при запуске.
При обновлении плагина ваши значения не перезаписываются, дописываются только новые параметры.

| Файл | Что внутри |
|---|---|
| `config.yml` | Часовой пояс, мир, спавн и его зона, граница мира, лобби, телепортация, чат, TAB, правила |
| `database.yml` | SQLite или PostgreSQL |
| `auth.yml` | Попытки входа, блокировка, сессии, требования к паролю |
| `economy.yml` | Стартовый баланс, потери при смерти и выходе из боя, лимиты /pay |
| `market.yml` | Динамические цены, магазин (категории и товары), скупка, аукцион, ордера, почта |
| `pvp.yml` | Боевой таймер, запрещённые в бою команды, контракты, усиленные мобы |
| `clans.yml` | Цена клана, размер, преемник лидера, правила войн |
| `items.yml` | Редкости, уникальные предметы, зелья, таблицы добычи, находки в структурах |
| `events.yml` | Расписание и типы событий, загадки, торговец, Незер и Энд |
| `npcs.yml` | NPC: облик, место, роль, диалог, действие, торговля |
| `dialogues.yml` | Разветвлённые диалоги |
| `quests.yml` | Задания |
| `progression.yml` | Уровни, репутация, ранги, титулы, достижения |
| `permissions.yml` | Служебные роли и права, причины наказаний, эскалация предупреждений |
| `logging.yml` | Сроки хранения журналов, резервное копирование |
| `performance.yml` | Сохранение профилей, пороги мониторинга, скорость отката |
| `duels.yml` | Мир дуэлей, число арен, время боя, наборы |
| `messages.yml` | Все тексты. Заполняется автоматически по мере использования; любую строку можно изменить |

## Значения, которые в ТЗ были открытыми (раздел 19), и что выбрано

Все они вынесены в конфиги, их можно поменять.

| Вопрос из ТЗ | Выбрано | Где менять |
|---|---|---|
| Цена создания клана | 50 000 (в 5 раз больше стартового баланса) | `clans.yml → create-cost` |
| Формула динамических цен | множитель = 1 + 0,10 × спрос / базовый объём, в пределах 0,70–1,30; спрос затухает на 5% каждые 10 минут; скупка не выше 80% цены покупки | `market.yml → dynamic`, `baseline` у каждого товара |
| Очки войны | убийство 10, блок 1; одна жертва засчитывается не чаще 3 раз в час; блок засчитывается, если его поставил враг не менее 10 минут назад, один раз за войну, не больше 60 очков за блоки в час на игрока | `clans.yml → war` |
| Ничья в войне | дополнительное время до первого очка, максимум 24 ч, затем ничья | `war.overtime-max-hours` |
| Мир по соглашению | война заканчивается без победителя | — |
| Распуск клана во время войны | победа противника | — |
| Преемник лидера | часы игры за 14 дней + взносы в банк за 14 дней / 1000; при равенстве — старший по стажу | `clans.yml → succession` |
| Распуск клана с деньгами в банке | банк возвращается лидеру | — |
| Выход из боя: нет источника урона | 10% сгорает | — |
| Выход из боя: равный урон | деньги получает тот, кто ударил последним | — |
| Кик и обрыв связи | кик администратором — без наказания; таймаут соединения считается выходом из боя | `pvp.yml → combat-logout` |
| Коллективное задание Энда | 512 жемчугов Края, 256 огненных стержней, 512 обсидиана, 128 алмазов; фонд 500 000 делится по вкладу | `events.yml → end` |
| Пороги вклада в событиях | 1–4 очка в зависимости от типа; после 30 однотипных действий их ценность падает; вклад AFK-игроков не засчитывается | `events.yml → types`, `diminishing-after`, `afk-seconds` |
| Осколки Незера | 5 штук; следующий получает лучший участник успешного события, пока Незер закрыт | `events.yml → nether` |
| Ритуал открытия Незера | ПКМ Ключом дальше 300 блоков от спавна, 3 волны за 10 минут; при неудаче ключ возвращается, повтор через 1 ч | `events.yml → types.ritual`, `nether` |
| Числа предметов и зелий | бонусы +1 урона/брони, пассивы со слабыми эффектами и перезарядкой | `items.yml` |
| Уровни | опыт до уровня L = 60 × L^1,6; +2 опыта за активную минуту; боевой бонус +0,02% урона за уровень, максимум +2% (в дуэлях не действует) | `progression.yml → levels` |
| Блокировка после 10 ошибок входа | 15 минут, по аккаунту и по IP; доверенная сессия с того же IP входит даже при блокировке | `auth.yml` |
| Хеширование паролей | PBKDF2-HMAC-SHA256, 600 000 итераций, соль 128 бит | `auth.yml → pbkdf2-iterations` |
| Регистраций с одного IP | не больше 3 (защита от мультиаккаунтов ради стартовых 10 000) | `auth.yml → max-accounts-per-ip` |
| Хранение журналов | действия — 60 дней (экономика, рынок, админ-действия и банки кланов — бессрочно), блоки — 30 дней | `logging.yml → retention` |
| Резервные копии | каждые 6 ч, хранить 12, с мирами | `logging.yml → backup` |
| Задержка телепортации | 3 с, отменяется движением или уроном | `config.yml → teleport.warmup-seconds` |
| Зона спавна | радиус 48 блоков, враждебные мобы не появляются | `config.yml → spawn-zone` |
| PvP-контракты | от 1 000, неисполненный контракт возвращается через 7 дней; клан-соратник цели и сам заказчик награду не получают | `pvp.yml → bounty` |
| Усиленные мобы | ночью 1% + 0,6% за каждые 1000 блоков от спавна (максимум 8%), здоровье ×1,5, урон ×1,25 | `pvp.yml → mobs` |

Оставлено ровно как в ТЗ: стартовый баланс 10 000, потери 10%, таймер боя 15 с, 2 дома, /tpa 120 с, /spawn 5 минут, кланы до 5 человек, войны до 7 дней, почта на 10 ячеек, аукцион без срока и комиссии, ордера без резервирования денег, тотем 100 000, элитры 1 000 000, мир 20 000 × 20 000, без приватов, Энд — через 7 дней после Незера плюс коллективное задание.
